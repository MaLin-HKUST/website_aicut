# 07. 术语表

本文回答什么问题：

- 项目里经常出现的关键术语具体指什么
- 哪些词在历史对话里容易被混用

## A 机器主服务器

指：

- 面向用户交付的网站主服务
- 包括网站前端、网站业务 API、admin、SQLite

不等于：

- 整个分布式系统的全部运行面

## A 机器调度中心

指：

- 调度 API
- Scheduler Runtime
- PostgreSQL

负责调度，不负责跑算法。

## Worker Gateway

指：

- 运行在 Worker 机器上的执行侧协调层

负责：

- 监听任务
- 心跳
- 下载输入
- 调算法
- 上传输出

## Smart Cut Worker

指：

- 纯算法执行镜像

只做处理，不做调度，不做 TOS 协调。

## SQLite

指：

- A 机器网站主服务器的数据底座

主要面向：

- admin
- auth
- 网站管理数据

## PostgreSQL

指：

- A 机器调度中心的数据底座

主要面向：

- 调度任务
- 设备状态
- Smart Cut 状态机

## TOS

指：

- 对象存储

在本系统中承担：

- 业务输入输出交换
- 跨机器数据传递
- 备份与归档

## Fake TOS

指：

- 本地文件系统模拟对象存储

只适合联调和测试，不应代表正式生产数据流。

## release manifest

指：

- 一次正式发布的结构化记录

应至少包含：

- git sha
- 镜像版本
- compose 版本
- 备份引用
- 验收结果

## release bundle

指：

- 一次正式发布所需的归档包

用于灾备和回滚。

## 主链路

指：

- 用户发起任务到看到结果的最核心链路

## 调度链路

指：

- A 机器将业务任务转成调度任务，并分配给 Worker 的链路

## 执行链路

指：

- Worker 读取任务、拉输入、跑算法、传回产物和状态的链路

## 对 Agent 的直接指令

- 如果一个词你无法在这里找到清晰定义，先补术语表，再继续改架构文档。
- 当历史对话里同一个词被混着用时，以这里的定义为准。
