# 00_system_knowledge

本文回答什么问题：

- 长期有效的系统知识有哪些
- 后续 Agent 应按什么顺序理解这个项目
- 哪些文档描述的是系统规则，而不是某一轮专项任务

## 本层定位

这一层是 `website_aicut` 的长期规则书。

它回答的是：

- 项目是什么
- 系统如何分布式拆分
- A 机器、Worker、TOS 的职责是什么
- 代码路径如何映射到系统角色
- 如何发布、如何备份、如何恢复
- Agent 在这个项目里有哪些禁区

它不回答：

- 当前线上到底乱成什么样
- 2026-04-18 这次为什么要重建
- 本轮重建时应该先清哪个目录

这些内容都在 `10_rebuild_2026-04-18/`。

## 对 Agent 的直接指令

- 普通功能开发只需要先读这一层，不要默认进入重建专项层。
- 只有在做架构、发布、备份、重建、回滚时，才需要再进入 `10_rebuild_2026-04-18/`。
- 如果你读完这一层后仍然打算把 Worker 逻辑放回 A 机器，说明你没有读懂系统定义，需要重读。
- 如果任务是页面改版、截图还原、UI 微调，请额外阅读 `08_前端协作模板.md`、`11_前端发布单一路径.md`、`09_前端页面修改上线Runbook.md`、`10_前端CodingAgent交付纯模板.md`。
