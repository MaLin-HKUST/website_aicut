## 当前最重要的风险

1. candidate API 和 Worker 依赖热补
- 当前功能可用
- 但发布真相还没有完全回到“git pull + build + deploy”

2. Worker Gateway 当前不是纯净镜像
- 当前启动依赖运行时 `pip install tos`
- 这必须回收进正式镜像

3. finalize 自动上传和自动回写仍有缺口
- Worker 能真实生成本地 `final_video.mp4`
- 但自动上传到 TOS、自动更新 `scheduler_tasks` / `smart_cut_tasks` 仍不稳定

4. A 机器历史目录尚未做文件级彻底清尾
- 当前不承载正式流量
- 但未来清理仍需谨慎，以免误伤回滚资产
