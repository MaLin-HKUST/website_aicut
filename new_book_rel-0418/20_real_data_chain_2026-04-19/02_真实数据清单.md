- `C2384_reencoded.mp4`：约 `109,975,797` bytes
- `C2384.MP4`：约 `3,825,788,875` bytes
- `ref.txt`：约 `5,161` bytes

## 本专项默认选择

本专项默认使用：

- 视频：`C2384_reencoded.mp4`
- 文案：`ref.txt`

默认理由：

- 它是真实样本
- 历史 acceptance 已经证明这组样本可用
- 传输和执行成本更低
- 更适合作为“正式链路真实闭环”的第一轮标准样本

## 不应再做的事

1. 不要再用临时 `printf 'sample bytes'` 生成的小视频文件代替真实样本
2. 不要让后续 Agent 去别的 harness 里重新搜索“真实数据在哪”
3. 不要在未记录原因的情况下，临时切换到 `C2384.MP4` 作为主样本

## 对 Agent 的直接指令

- 本轮真实数据联调默认从 `C2384_reencoded.mp4 + ref.txt` 开始。
- 如果你决定切到 `C2384.MP4`，必须在执行报告里明确写出原因。
