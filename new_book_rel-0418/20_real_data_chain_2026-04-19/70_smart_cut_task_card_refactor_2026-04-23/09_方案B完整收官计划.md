### B1-2 S205: Abandoned 7天清理规则

**现状**
- 放弃的任务标记 `abandoned_at`，但没有自动清理机制
- 中间产物（runs、edits、TOS 文件）会一直累积

**具体工作**
1. 在 `apps/scheduler/` 或 `apps/services/` 中实现清理服务：
   ```python
   def cleanup_abandoned_tasks():
       cutoff = datetime.utcnow() - timedelta(days=7)
       abandoned_tasks = db.query(SmartCutTask).filter(
           SmartCutTask.abandoned_at < cutoff
       ).all()
       for task in abandoned_tasks:
           # 清理 runs
           db.query(SmartCutTaskRun).filter_by(task_id=task.id).delete()
           # 清理 edits
           db.query(SmartCutEdit).filter_by(task_id=task.id).delete()
           # 清理 TOS 中间产物（保留 final_video 如果有）
           cleanup_tos_intermediate(task.id)
   ```
2. 集成到现有 scheduler 心跳或启动流程中（每天执行一次）

**清理范围**
| 对象 | 是否清理 | 说明 |

| `smart_cut_task_runs` | ✅ 清理 | 子执行记录 |
