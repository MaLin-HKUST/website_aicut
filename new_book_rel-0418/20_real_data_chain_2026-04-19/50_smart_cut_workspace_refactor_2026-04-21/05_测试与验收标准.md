# 05_测试与验收标准

## 页面验收

- 多次点击“智能剪气口”，任务中心不再新增空上传任务
- 上传视频和文案后，切页/刷新/关标签再回来，状态仍恢复
- analyze 完成后：
  - 文本框出现 script
  - 删除线可见
  - `audio_a` 自动可播放
- preview 完成后：
  - `audio_b` 自动可播放
- finalize 点击后：
  - 工作台清空
  - 任务中心新增一条正式任务
  - 标题带北京时间戳

## API 验收

- 进入 `/smart-cut` 时不再调用 `create_task`
- 当前会话草稿可被恢复
- 同一用户同一会话只返回一条活动草稿
- finalize 前 `visible_in_task_center = false`
- finalize 后 `visible_in_task_center = true`

## 数据库验收

- `smart_cut_tasks` 新字段存在
- 历史中间态任务已隐藏
- finalize 时标题、可见性、状态在同一事务内更新

## Worker / TOS 验收

- analyze 继续产出：
  - `script`
  - `asr`
  - `audio_a`
- preview 继续产出：
  - `edited_delay_cuts`
  - `audio_b`
- finalize 继续产出：
  - `final_video`
- 页面显示与 TOS / Worker 结果一致

## 真实浏览器回归

必须按 `40_headed_browser_e2e_2026-04-21/task.json` 再跑一轮：

- 登录
- 上传真实样本
- analyze
- 修改删除线
- preview
- finalize
- 任务中心下载

## 不算通过的情况

- 页面“看起来差不多”，但任务中心仍有空任务
- analyze 结果生成了，但页面没自动回显
- preview 成功了，但右侧播放器没切成 `audio_b`
- finalize 进入任务中心了，但当前工作台没清空
