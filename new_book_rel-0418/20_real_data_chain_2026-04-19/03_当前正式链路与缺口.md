这意味着：

这意味着：

## 为什么现在必须做真实数据联调

原因很直接：

1. 现在系统已经不是“完全不可用”的紧急状态
2. 现在最关键的问题从“能不能跑”变成了“哪一段已经真实通过，哪一段还靠人工收口”
3. 如果不把真实样本闭环补上，后续任何 Agent 都会把 phase 7 的假样本成功误判成真实业务成功

## 当前专项的边界

本层只负责回答：

- 用真实样本把正式链路跑通
- 留下真实证据
- 写清当前还剩哪些收口项

本层不直接等同于：

- 发布系统重构
- 镜像系统重构
- Worker 全环境完善
- 原始大文件压力测试

这些属于下一阶段或后续专项。

## 当前最关键的缺口列表

1. finalize 自动上传 / 自动回写已完成代码级修复，但新的真实回归任务仍需继续观察最终自动收口结果
2. Worker Gateway 仍依赖运行时动态安装 `tos`
3. 热补未进入标准构建
4. 旧证据目录已经补进 `artifact_manifest.json / artifact_index.md / sanitized_summary.md`
5. 新的真实回归任务 `a33438e1-6aab-4b45-ac03-d9a9eb9ab16a` 仍在执行中
