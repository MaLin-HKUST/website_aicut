## 一、项目核心定位

| 属性 | 说明 |
|------|------|
| **产品名称** | 智能剪口播气口 / 粗剪 (Smart Cut) |
| **核心功能** | 自动识别并剪辑视频中的错误、停顿、语气词 |
| **任务类型** | 分步任务 (analyze → preview → finalize) |
| **用户交互** | 支持用户调整删除范围、试听、选择输出规格 |

---

## 二、三阶段任务流程

```
┌──────────┐      ┌──────────┐      ┌──────────┐
│ analyze  │ ───→ │ preview  │ ───→ │ finalize │
│  分析阶段  │      │  试听阶段  │      │  生成阶段  │
└──────────┘      └──────────┘      └──────────┘
     │                  │                  │
     ▼                  ▼                  ▼
  ASR识别            用户调整删除线         输出最终视频
  生成script         生成audio_b试听       GroundTruth投喂
  生成audio_a
```

### 各阶段详细说明

| 阶段 | 职责 | 输入 | 输出 | Worker队列名 |
|------|------|------|------|-------------|
| **analyze** | 分析原视频，识别口播气口 | 原视频URL、参考文案URL | ASR结果、script（大括号格式）、audio_a、delay_cuts | `smart_cut_analyze` |
| **preview** | 基于用户修订生成试听 | 用户修订后的script、ASR结果、原视频 | edited_delay_cuts、audio_b、pause_cuts_on_original | `smart_cut_preview` |
| **finalize** | 生成最终视频 | cuts配置、输出规格(original/vertical_1080p) | 最终视频MP4、GroundTruth数据 | `smart_cut_finalize` |

## 四、核心数据格式与协议

### 4.1 脚本格式（前后端协议）

| 位置 | 格式 | 示例 |
|------|------|------|
| **后端存储** | 大括号格式纯文本 | `今天天气{嗯}很好{啊}` |
| **前端展示** | 删除线 HTML | `今天天气<del>嗯</del>很好<del>啊</del>` |
| **转换方向** | 双向转换 | 大括号 ↔ 删除线 |

### 4.2 Pause Cuts 格式（DirectCutter兼容）

```json
{
  "cut_segments": [
    {
      "start_time": 1234,
      "end_time": 1567,
      "type": "pause",
      "position": ""
    }
  ]
}
```
- 时间单位：**毫秒**
- 必须包含 `position` 字段（可为空字符串）

### 4.3 输出规格参数

| 规格 | 是否normalize | 码率控制 | 说明 |
|------|--------------|----------|------|
| `original` | ❌ 否 | `min(input_bitrate, 12Mbps)` | 保持原视频尺寸 |
| `vertical_1080p` | ✅ 是 | `min(input_bitrate, 12Mbps)` | 归一化为1080P竖屏 |

### 4.4 码率计算公式

```python
output_bitrate = min(input_bitrate, 12_000_000) if input_bitrate else 12_000_000
maxrate = output_bitrate
bufsize = output_bitrate * 2
```

## 五、TOS存储路径规范

### 5.1 输入文件
- 原视频：`smart-cut/{task_id}/input/source_video.mp4`
- 参考文案：`smart-cut/{task_id}/input/reference.txt`

### 5.2 输出文件
- 最终视频：`smart-cut/{task_id}/final/final_video.mp4`
- 试听音频：`smart-cut/{task_id}/preview/audio_b.mp3`

### 5.3 GroundTruth数据
```
cujian_input_data/{company}/{year-month}/cujian_userdata_{timestamp}/
├── reference.txt           # 标准文案
├── analyze_script.txt      # 系统输出的script
├── edited_script.txt       # 用户修改后的script
├── asr_result.json         # 输入视频的ASR结果
└── metadata.json           # 元数据（task_id、公司、时间戳等）
```

## 七、核心约束与规则

| 规则 | 说明 |
|------|------|
| **Worker不阻塞** | 等待用户交互时释放Worker，任务进入waiting_user状态 |
| **audio_b仅试听** | audio_b不参与最终视频合成，只用于前端试听 |
| **基于原视频** | analyze/preview阶段始终基于原始上传视频处理 |
| **normalize时机** | 只在finalize阶段且选择1080P竖屏时执行 |
| **码率规则** | 必须生效 `min(input_bitrate, 12Mbps)` |
| **前端直传** | 大文件（视频）前端直传TOS，API只记录URL |
| **GroundTruth** | 只在finalize阶段、勾选投喂时上传 |
