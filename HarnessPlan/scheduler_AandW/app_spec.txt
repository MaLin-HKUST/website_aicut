Goal

- Keep formal product code under /Users/malin13/Documents/trae_projects/website_aicut

Architecture contract
- A-machine business server is already online and remains separate.
- A-machine scheduler center and Worker gateway both connect directly to the same PostgreSQL scheduler database.
- Worker gateway is machine-level infrastructure, not an algorithm image.
- Smart-Cut algorithm image stays separate from Worker gateway.
- Worker gateway and algorithm image exchange data via shared work directory + task_manifest.json + result_manifest.json.
- TOS download/upload is owned by Worker gateway, not by the algorithm container.
- A-machine scheduler center writes scheduler task state.
- Worker gateway writes worker device state.

Current grounded status
- The root deployed compose still targets web + api + sqlite, not the final A-machine scheduler-center topology.
- apps/scheduler contains scheduler-center service code, but deployment/runtime completion is not yet proven.
- worker/ contains Worker gateway code and combined-image experiments, but the formal separated gateway + algorithm-image topology is not yet finished.
- worker code and Docker files currently have uncommitted edits in the main repo; harness bootstrap must not mix those changes into its own commit.

- Harness artifacts exist and are the only source of feature tracking.
- One feature at a time, each finished feature is verified and committed independently.
- Image outputs are written to /Volumes/XIAOMA-A-1T/docker_hub/WorkerGateway_and_Ascheduler
