目标
- 在 website_aicut 的 apps/api 中实现一套可测试的任务调度系统。
- 使用 Harness 模式管理这项工作，保证跨 session 可恢复、可验证、可逐步发布。
- 用 TDD 先锁定状态机和调度规则，再接入 SQLAlchemy 与 FastAPI。

核心能力
- A 负责任务表写入与业务推进。
- Worker 负责设备表写入与执行状态上报。
- 支持单步任务、分步任务、人工后处理任务。
- 支持用户离开、72 小时内恢复、主动放弃、超时关闭。
- 支持 FCFS + 能力匹配 + 空闲设备分配。
- 支持执行失败、心跳异常、握手异常、post 卡住等报警记录。

必须遵守的约束
- 任务表只能由 A 写，Worker 只读。
- 设备表只能由 Worker 写，A 只读。
- 一个 Worker 一次只处理一个任务。
- 当前版本不做自动重派、运行中断自动恢复、复杂优先级、多任务并发。
- waiting_user / suspended / post / failed 期间保留 workspace。
- abandoned 立即删除 workspace。
- timeout_closed 在超过 72 小时后清理 workspace 且不可恢复。
